A lightweight Python library that brings Go-style concurrency patterns to Python developers. It provides routines, channels, select blocks, and WaitGroups without requiring C extensions. Designed for free-threaded Python builds, it enables parallel CPU workloads and structured concurrent pipelines with zero third-party dependencies.
