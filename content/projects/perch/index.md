A fast, local-first Android link manager built with Flutter. Save links from the
Android share sheet or in-app, organise them in nested folders and tags, auto-fetch
link metadata and favicons on device, and treat every link as a small markdown note.
No account, no backend, no tracking, just one SQLite file on the device with
full-text search.
