A native Android version of PostPurush built in Flutter with Material 3 Expressive.
Compose HTTP requests, organise work into nested collections, manage environment
variables with masked secrets, and inspect folded JSON responses. Includes an offline
catalogue of public APIs, on-device latency analytics, assertion and load testing,
and PDF documentation export. Everything runs locally on device with no account, no
sync and zero telemetry.
